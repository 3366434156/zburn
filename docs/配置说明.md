# 配置说明

所有配置都在一个 JSON 里，`zburn.py --config config.json` 指定；也可以设环境变量
`ZBURN_CONFIG`，或者干脆不写配置走内置默认值。默认值会被深合并，所以只写你要改的字段就行。

```jsonc
{
  "app": {
    "process_name": "ZCode",                    // 进程名（Get-Process -Name 用的那个）
    "exe": "E:\\exe\\Zcode\\ZCode.exe",         // 崩了要拉起的可执行文件
    "start_args": [],                           // 启动参数
    "strip_env": ["ELECTRON_RUN_AS_NODE"],      // 拉起前要清掉的环境变量（Electron 必填）
    "start_if_down": true                       // 是否自动拉起
  },
  "uia": {
    "send_button_regex": "发送|加入队列|立即|Send",
    "busy_regex": "停止生成|Stop generating",   // 出现它 = 正在输出
    "queued_regex": "移除待发送消息|Remove queued", // 出现它 = 已有排队消息
    "session_regex": ".",                       // ⚠️ 只投喂名字匹配的会话，强烈建议收紧
    "max_depth": 40,                            // 控件树遍历深度
    "char_delay_ms": 20                         // 每字间隔（丢字就加大）
  },
  "prompt": {
    "templates": ["Continue ...", "Keep going ..."],  // 轮换，避免每次同一句
    "file": "next-prompt.txt"                          // 当前指令落盘位置（人可读可改）
  },
  "feed": {
    "max_sessions": 5,                          // 一轮最多喂几个会话
    "interval_seconds": 120                     // 巡检间隔
  },
  "gateway": {
    "health_url": "http://127.0.0.1:3000/meta",
    "start_command": "python -m uvicorn app.main:app --port 3000",
    "work_dir": "E:\\数据\\AI\\zcode2api",
    "grace_seconds": 60,                        // 探活失败先等 60 秒再判定真的挂了
    "keep_alive": true                          // 关掉就完全不碰网关
  },
  "quota": {
    "provider": "none",                         // none | gateway_zcode2api | command
    "url": "http://127.0.0.1:3000/admin/api/accounts",
    "admin_key": "",
    "refresh_url": "http://127.0.0.1:3000/admin/api/accounts/refresh",
    "refresh_body": { "all": true },
    "refresh_every_seconds": 600,
    "stop_below": 0,                            // 剩余 ≤ 它就收工；0 = 永不因额度停
    "command": ""                               // provider=command 时执行它
  },
  "paths": {
    "state_dir": ".zburn",                      // 日志/状态/心跳都在这
    "stop_file": "STOP"                         // 出现这个文件 run 就收工
  },
  "watchdog": {
    "heartbeat_stale_seconds": 420,             // 心跳超过它没更新 → 重启 run
    "check_seconds": 30
  }
}
```

## 常用改法

### 只喂我这个项目的会话

```json
"uia": { "session_regex": "Supervisor:|着色器|完美世界" }
```

不给的话（`.`）会把侧栏里**所有**会话都当候选——包括跟当前任务无关的。

### 换个应用（以记事本举例）

```json
"app": { "process_name": "notepad", "exe": "C:\\Windows\\System32\\notepad.exe" },
"uia": {
  "send_button_regex": "Send",
  "busy_regex": "Stop",
  "queued_regex": "Cancel",
  "session_regex": "."
}
```

改之前先跑 `zburn.py probe --filter "Edit|Button"` 看控件长什么样。

### 用命令取额度（不接网关）

```json
"quota": {
  "provider": "command",
  "command": "curl -s https://api.example.com/balance",
  "stop_below": 500000
}
```

命令 stdout 里第一个 ≥4 位的整数会被当成剩余额度。

### 不想让它碰网关

```json
"gateway": { "keep_alive": false }
```

### 一轮多喂几个会话

```json
"feed": { "max_sessions": 5, "interval_seconds": 120 }
```

并行会话数受后端账号并发限制，超过会出现排队/429。实测 5 个是舒服的上限。

## 字段速查

| 字段 | 影响 |
|---|---|
| `uia.char_delay_ms` | 打字速度。小=快但可能丢字；20~25 稳 |
| `uia.max_depth` | 控件树太深会慢；40 够用 |
| `feed.max_sessions` | 一轮投喂上限（受后端并发限制） |
| `feed.interval_seconds` | 巡检周期。太小会反复空转，120 秒是经验值 |
| `quota.stop_below` | 收工阈值 |
| `quota.refresh_every_seconds` | 主动刷新额度的间隔（有些后端要主动刷才更新） |
| `gateway.grace_seconds` | 探活失败后的冷静期，避免把"正在重启"误判成"挂了" |
| `watchdog.heartbeat_stale_seconds` | 守护进程被认为卡死的时间 |
| `paths.stop_file` | 手动收工开关（文件存在即停） |
